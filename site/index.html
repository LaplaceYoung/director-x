Infinite media canvas

Production evidence stays visible.

Images, video, audio, scripts, shot lists, storyboards, color systems, and generation prompts appear as previewable DAG nodes. Internal Agent state and technical logs stay out of the creative canvas.

What Director X does

One focused video workflow.

01

Reference-video analysis

Download approved sources, inspect metadata, separate audio, extract frames, estimate scene cuts, and generate shot boards and color cards.

02

Video planning on an infinite canvas

Keep research, scripts, storyboards, visual systems, images, audio, video, and dependency relationships in one reviewable workspace.

03

AI image and video prompt engineering

Write provider-aware prompts with continuity locks, negative constraints, target specifications, and single-variable repair guidance.

04

Production without an API key

Create generation placeholder nodes containing the expected output, complete prompt, recommended model routes, and technical parameters.

05

Remotion composition and rendering

Turn approved media and production text into simple programmable video sequences, preview renders, and final MP4 output.

Codex-native workflow

Research, decide, make, review.

Codex remains the host. Director X adds video-specific skills and tools without creating another chat system, desktop app, or MCP runtime.

  1. ClarifyCodex asks one material question at a time.
  2. UnderstandFFmpeg evidence supports shot, color, motion, and audio analysis.
  3. DirectBuild the visual system, script, storyboard, and production prompts.
  4. ProduceAcquire, generate, or preserve missing shots as explicit placeholders.
  5. ComposeUse Remotion for simple editing, sequencing, and MP4 rendering.

Local development

Run Director X from the repository.

Director X currently targets Codex on macOS with Node.js 22 or later.

git clone https://github.com/LaplaceYoung/director-x.git
cd director-x
npm install
npm run ci

node scripts/directorx.mjs doctor
node scripts/directorx.mjs init --project /path/to/video-project
node scripts/directorx.mjs canvas --project /path/to/video-project

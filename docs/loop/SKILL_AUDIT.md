## Findings

- The entry skill correctly owns implicit invocation and says canvas-first, Goal-first, and native-input-first.
- Specialist metadata is consistently explicit-only, which prevents most trigger conflict.
- `directorx-production-orchestration` is intentionally post-boot, but its description still needs to be kept clearly subordinate to `directorx`.
- The skill catalog is too broad for a first-time user even though the invocation policy is safe. Consolidation should happen through routing and Facades, not by deleting production knowledge prematurely.

## Decision

Do not delete skills in loop 01. First measure real invocation and build one stable user-intent route. A skill can be retired only when its guidance is represented in a tested parent route and no artifact contract is lost.

# Visual prompt writing

## Image prompt

Specify subject identity, action, environment, composition, shot size, camera position, lens character, lighting direction, color relationship, material, atmosphere, aspect ratio, continuity anchors, and exclusions.

## Video prompt

Describe an observable temporal change:

1. opening state
2. subject action
3. camera movement
4. environmental movement
5. timing and speed
6. ending state
7. continuity constraints
8. forbidden changes

Avoid adjective piles. Prefer physical direction the model can render. Preserve only the dimensions that must remain consistent between shots.

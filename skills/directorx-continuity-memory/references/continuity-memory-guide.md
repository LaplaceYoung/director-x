# Continuity Memory Guide

## Memory Buckets

- Product: name, color, geometry, logo, claims, forbidden claims.
- Character: identity, outfit, voice, relationship, emotional state.
- Scene: place, time, layout, lighting, props.
- Style: palette, camera grammar, edit rhythm, caption system.
- Voice: speaker, speed, tone, pronunciation, terminology.
- Music: motif, BPM range, intensity, ducking moments.
- Timeline: shot order, cause/effect, callbacks, unresolved promises.
- Approval: user-approved brief, budget, delivery promise, platform target.
- Failure: rejected prompt, provider failure, visual defect, policy blocker.

## Drift Response

- Minor drift: repair prompt and retry within attempt budget.
- Repeated drift: reroute provider or simplify shot.
- Approved fact drift: stop at approval gate.
- Budget drift: reduce nonessential shots before touching promised shots.

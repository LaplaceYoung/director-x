# DirectorX Screen Demo Production

Use this skill for videos where a screen, app, website, or software workflow is the main subject.

## Workflow

1. Define user task and success state before recording or generating visuals.
2. Script visible actions, narration, zooms, callouts, and pauses together.
3. Keep UI text legible for vertical and horizontal variants.
4. Plan cursor movement and focus areas as shot objects.
5. Reserve subtitle and callout zones.
6. Export platform variants with readable crop, zoom, and captions.

## Output Contract

```json
{
  "demo_task": "",
  "screen_shots": [],
  "cursor_plan": [],
  "callouts": [],
  "caption_safe_area": {},
  "export_variants": []
}
```

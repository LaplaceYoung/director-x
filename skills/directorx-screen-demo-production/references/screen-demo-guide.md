# Screen Demo Guide

## Shot Rules

- Show the outcome early.
- Zoom only when it improves comprehension.
- Avoid rapid cursor wandering.
- Use callouts for decisions, not every click.
- Keep important UI away from subtitle zone.
- For vertical versions, crop around the active panel and add context labels.

## Audio

- Narration explains why the action matters.
- SFX should be minimal and tied to state changes.
- Music stays low enough for speech clarity.

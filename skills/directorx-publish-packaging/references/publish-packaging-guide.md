# Publish Packaging Guide

## Platform Packaging

| Platform | Packaging Focus |
| --- | --- |
| Douyin | Title promise, strong cover contrast, comment prompt, trend-compatible tags. |
| Kuaishou | Practical value, authentic wording, community-friendly question. |
| Bilibili | Accurate title, chapter description, source links, topic partition fit. |
| Xiaohongshu | Searchable title, list-like cover, save/share reason, lifestyle tags. |
| WeChat Channels | Trustworthy headline, public-account linkage, shareable summary. |

## Title Checks

- Title names the payoff or question.
- Cover text can be understood in one glance.
- Hashtags reflect content, audience, and platform topic taxonomy.
- CTA asks for one action.
- Sensitive claims are softened or sourced.
